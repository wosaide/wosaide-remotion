# WOS Aide Icon Kit Changelog

## 1.0.1 - 2026-09-14

- Removed the old circular background from platform icons.
- Light theme: black bird on transparent background.
- Dark theme: white bird on transparent background.
- Rebuilt Xcode, Electron, Windows, and Chrome icon assets from the same SVG geometry.
- Added the Xcode theme-aware BirdMark imageset.
- Release tag: `icons-v1.0.1`.

## 1.0.0 - 2026-09-14

- Initial cross-platform icon package.
- Superseded by 1.0.1 because the raster package inherited the circular background from the visual reference PNG.
